Band motif background asset

One inline SVG — charcoal base, coral/lime/off-white diagonal bands, halftone corner, concentric arcs off the right edge, ring-and-dot motif. Left ~25% and right ~20% stay flat for logo/headline placement. Themed entirely through four CSS classes (band-ink / band-hot / band-volt / band-paper) driven by custom properties — try the palette switcher below.

Technical requirements checklist

✓ Plain hex in fill/stroke presentation attributes, no var() inside the SVG itself
✓ Four themeable classes (band-ink / band-hot / band-volt / band-paper) + external CSS rule block (theme.css)
✓ preserveAspectRatio="xMidYMid slice" on the root <svg>
✓ role="img" + aria-label on the root <svg>
✓ Content wrapped in a clipPath — bands overshoot the canvas by design, cropped cleanly
✓ No external references, no embedded fonts, no raster images — pure inline vector
✓ Left ~25% / right ~20% verified flat at every visible row (computed, not eyeballed — see README)
