## Sampling Rate

- **After every task commit:** Run the targeted `swift test --filter <NewSuite>` or `xcodebuild test -only-testing:RithamTests/<NewSuite>` for whatever that task touched.
- **After every plan wave:** Run the full `swift test` (RithamCore) and full `xcodebuild test` (RithamApp).
- **Before `/gsd-verify-work`:** Full suite must be green, plus both structural negative tests (no em/en dash in new Copy; no `HomeHubView`/`OnboardingStep` reachability for `KidIdeasView`) passing explicitly.
- **Max feedback latency:** ~30s per task (RithamCore-only tasks); full Xcode suite reserved for wave boundaries, matching this project's existing precedent (STATE.md Phase 2/3 close-out notes).
