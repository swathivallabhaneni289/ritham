## Sampling Rate

- **After every task commit:** `go test ./...` (backend tasks) or the relevant targeted `xcodebuild test -only-testing:` invocation (client tasks)
- **After every plan wave:** Full `go test ./...` plus full `xcodebuild test` (matching Phase 2/Phase 3's `StepRegistry` cross-suite-serialization precedent — any new test suite touching shared static state must respect `.serialized`, see `STATE.md`)
- **Before `/gsd-verify-work`:** Full suite green, plus the two required structural negative tests (EXIF-strip, certificate-uses-stripped-photo) passing explicitly
- **Max feedback latency:** ~120s (matches this project's existing full-target xcodebuild precedent; no faster targeted-suite convention established yet for this phase)
