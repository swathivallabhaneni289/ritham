- `GroupVisibilityScope` ships exactly two reachable rungs (`onlyMe`, `group`); `GroupVisibilityScope(rawValue: "household")` provably returns `nil` since no case exists for it to resolve to, matching `MomentumVisibility`'s Phase 3 precedent for the identical problem.

## Decisions Made
- `PrivateCompletionDetail` stays inside `GoalEventModels.swift` rather than a separate file: the plan's own `files_modified` frontmatter caps this plan at exactly seven source files, and the artifacts_produced section places it there explicitly. The threat model's T-04.1-06 mitigation text ("declared in a separate file from every group-visible type") is satisfied in spirit via the type's own doc comment stating the never-referenced-by-network-type invariant; the enforcing gate is deferred to plan 04.1-10's reflection-based wire-contract shape lock, as the threat register itself states.
- `SocialSession` is `Sendable`/`Equatable` but intentionally not `Codable`, matching the plan's own artifact spec (which lists `Codable` for every other identity type but not this one) -- a session token is bearer-sensitive and this type is never serialized as a JSON field on a broader payload.
- `SocialCopy.Feed.card(name:eventName:time:)` uses 04.1-UI-SPEC.md's house-style "in {time}" rewrite ("...Saturday 5K Walk in 32:14.") rather than `docs/group-events.md`'s raw em-dash original ("...Saturday 5K Walk — 32:14."), per the plan's own instruction that UI-SPEC already supplies the house-style rewrite as the transcription source.
- `Groups.leaveGroupConfirmation` extends the house-style dash-substitution convention to a fourth string beyond the PRD's own two locked em-dash rows: 04.1-UI-SPEC.md's own suggested "Claude's Discretion" wording for this confirmation also contained an em dash, rewritten here with a period split for the same house-style reason.
- The banned-lexicon sweep in `SocialCopyTests` bans phrases ("pooled total," "leaderboard," "first to complete," etc.) rather than bare word stems, specifically because this file's own locked string ("There's no clock and no ranking...") legitimately *negates* the banned concept -- a bare "rank" stem would false-positive against it.
