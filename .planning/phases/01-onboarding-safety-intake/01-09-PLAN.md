<objective>
Clear this phase's hard environment blocker, stand up the iOS app target, and build the single shared
navigation container that structurally guarantees CROSSGEN-05.

Purpose: Xcode is not installed on this machine. Verified during planning: `xcode-select -p` resolves to
`/Library/Developer/CommandLineTools`, `xcodebuild` reports "requires Xcode, but active developer
directory is a command line tools instance", `xcodebuild -showsdks` lists no iOS SDK, and no
`Xcode.app` exists in `/Applications`. Waves 1 through 3 were deliberately sequenced so that every
safety-critical rule — the sixteen escalation rules, calibration thresholds, and the routing guarantee —
is already green before this blocker is reached. Everything from here needs a real iOS SDK.

The navigation root belongs here rather than with the step views because it must have exactly one owner.
Three later plans add screens and two later plans touch the app entry point; centralising the container
and the step registry now means a screen is contributed by conforming to a protocol, never by editing a
shared switch statement that would become a merge point and, worse, a place where an age-based branch
could creep in.

Output: A buildable iOS app target consuming `RithamCore`, and one navigation container hosting every
step.
</objective>

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
