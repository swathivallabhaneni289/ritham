<objective>
Close Phase 2: fix the pre-existing test-concurrency defect that makes a full-target run
untrustworthy, assert phase-wide step coverage, and run the verifications a simulator cannot
perform.

Purpose: every earlier plan in this phase gates on targeted test runs because a full-target run
intermittently reports registered steps as unregistered. `STATE.md`'s Blockers section documents the
root cause: the step registry's shared static state races across Swift Testing suites that run
concurrently, and each suite's own serialization trait only orders tests within that suite. Phase 2
adds several more registry-touching suites, so this must be fixed before the phase's own full-suite
gate means anything.

Three verifications in `02-VALIDATION.md`'s Manual-Only table cannot run in a simulator: real GPS
measurement, real motion classification, and the cross-process round trip to the local Go service.
A fourth is carried from Phase 1: the radial session timer has never been read at the largest
accessibility text sizes because its only host screen was unreachable. Plan 02-13's pre-assessment
screen makes it reachable, so that check is now dischargeable rather than deferrable again.

Output: one serialization fix, one phase-coverage suite, and two human-verified checkpoints.
</objective>
